# Agent Guide

Read this file before changing the repository. `README.md` is the user-facing
source of truth; keep it synchronized with behavior and commands.
Update this guide and `.cursor/rules/project-context.mdc` proactively whenever
architecture, invariants, operational commands, or required checks change.

## Product

MediaArchivistBot indexes new media from Telegram groups and retrieves original
messages by semantic search. It does not persist media binaries.

- Private plain-text, `/search`, and `/find` queries span only groups where live
  membership is confirmed.
- Inline search (`@bot <query>`) uses the same membership-scoped archives.
  Telegram does not expose the current chat id on inline queries, so inline
  mode cannot be restricted to a single group.
- `/search` and `/find` inside a group search only that group's archive.
- The bot must be a group administrator for indexing and reliable membership
  checks.
- Messages authored by this bot or sent through this bot must never be indexed.
  Other bots are skipped unless `INDEX_BOT_MEDIA=true`.
- Telegram cannot expose history from before the bot joined, protected content,
  deleted messages, or standard Bot API downloads above 20 MB.

## Runtime architecture

- `mediaarchivistbot`: Python 3.12 async Telegram bot and indexing worker.
- `db`: PostgreSQL 17 with pgvector; all schema changes go through Alembic.
- `ollama`: local `qwen3-embedding:0.6b`, producing 1024-dimensional vectors.
- Vision: AnyModel-hosted `ag/gemini-3.7-flash-medium` through the
  OpenAI-compatible chat completions API.
- Video: scene-aware frames plus local `faster-whisper`; animations skip audio.
- Search: cosine vectors + PostgreSQL FTS/trigrams with RRF.
- Search returns up to 5 results. Semantic candidates require cosine distance
  `<= 0.65`; lexical FTS matches or trigram similarity `>= 0.12` can also enter.
  There is currently no cutoff relative to the best result's score.

Key modules are `bot.py`, `worker.py`, `llm_api.py`, `media_processing.py`,
`search.py`, `models.py`, and `config.py`.

## Non-negotiable invariants

- Repository documentation, UI strings, prompts, comments, and fixtures are in
  English. Search aliases generated by the vision model include English and
  Russian.
- The archival prompt must accurately describe controversial, profane, or
  politically sensitive memes without moralizing or inventing content.
- Authorization is fail-closed. Filter allowed `chat_id` values before ranking
  or forwarding private-search results.
- Do not replace live membership checks with a stale positive cache.
- Never call `create_all()` or run schema DDL from application imports.
- Keep every Alembic revision and `alembic.ini` in Git.
- Never log API payloads, authorization headers, media bytes, or secrets.
- Never commit `.env`, media samples, evaluation cases, backups, notebooks,
  database files, or credentials. `img/`, `eval/`, and `backups/` stay ignored.

## Local operations

Check existing services before starting anything:

```bash
docker compose ps
```

Compose defaults to `ghcr.io/netherquartz/mediaarchivistbot:latest` with
`BOT_PULL_POLICY=always`. CI rebuilds and tests on every `main` push, and
publishes that image to GHCR when a git tag is pushed. For local builds use
`BOT_PULL_POLICY=build docker compose up --build -d`.

Common commands:

```bash
docker compose up -d mediaarchivistbot
docker compose logs --since=5m mediaarchivistbot
./scripts/backup.sh
./scripts/restore.sh path/to/backup.dump
```

After changing prompts or embedding semantics, version the prompt/model metadata
and explicitly reindex affected rows. Do not silently compare vectors generated
by different embedding models.

## Required verification

Before reporting commit readiness:

```bash
docker compose config --quiet
docker compose build migrate
docker compose run --rm -e RUN_DB_TESTS=1 migrate python -m pytest -q
docker compose run --rm migrate alembic check
docker compose run --rm --no-deps migrate pip check
python -m compileall -q archivistbot migrations tests
sh -n scripts/backup.sh scripts/restore.sh
git diff --check
```

Also scan prospective Git files for secrets and confirm ignored local artifacts
are absent from `git status`. Do not create commits unless explicitly requested.
